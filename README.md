# Guaranty-Trust-Bank---Audit Readiness Case Study
Project Topic: Branch Audit Readiness Through Daily Call-Over Reviews

Organization: Guaranty Trust Bank  
Role: Customer Relationship Manager
Responsibility: Pre-audit preparation and corrective-action coordination

Reported outcomes: approximately 65%–75% → 95% audit performance | about 30% fewer errors. Illustrative scope: 145,000 transactions.

Problem

Documentation errors and transaction omissions had affected previous audits. Waiting until formal audit preparation allowed issues to accumulate. The portfolio reconstruction uses 145,000 transactions as an illustrative review scope; it is not a verified count or a claim that I personally checked every transaction.

Task

Identify issues earlier, coordinate corrections, and support readiness for internal audits every six months and annual external audits.

Action

Introduced an end-of-day call-over process for completed transactions and documentation.

Checked for inaccuracies, missing information, and omissions.

Contacted responsible teams to arrange corrections.

Coordinated with Operations, Tellers, Account Managers, Fraud, AML, and Cybersecurity as needed.

Used daily reviews to support ongoing audit preparation.

Results

My reported outcome was an improvement from approximately 65%–75% to 95% in audit performance, an increase of 20–30 percentage points, with errors declining by approximately 30%.
